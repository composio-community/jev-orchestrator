# Support notes

<!-- Steps the support agent may give. If a problem is not here, it asks for details and stops. -->

## Can't log in
1. Reset the password from the login page.
2. Check the spam folder for the reset email.
3. If they use Google sign-in, make sure it is the same Google account they signed up with.

## Reminders not sending
Ask for the booking date/time and the client's phone number format. Check Settings → Reminders is on. SMS only works in US/UK/CA/AU.

## Billing looks wrong
Ask for the account email and the date on the invoice. Do not promise a refund.
